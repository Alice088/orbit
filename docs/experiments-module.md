## Что это

Эксперимент — универсальная карточка «что я меняю → как измеряю → что получилось». Это не TODO, не привычка и не дневник, а контейнер для любых маленьких улучшений: методика ведения списка задач, запоминание карточек, режим работы, обучение, сон.

Всё держится на пяти принципах:

- гибкость — любые темы;
- быстро — 30 секунд на ввод;
- легко — минимум полей;
- история — все прошлые попытки сохраняются;
- сравнение — видно, какие мелочи реально дали результат.

## Семья и версии

Эксперимент — это семья версий. Название, категория и теги описывают семью; каждая версия — отдельный забег со своим изменением, метриками, baseline, чек-инами и результатом.

v1 → v2 → v3 — версии не перезаписываются. Новая версия — форк предыдущей: поправь метод и начни заново. Если форк происходит в середине забега, текущая версия помечается прерванной и больше не влияет на статистику семьи.

## Метрики

Шесть универсальных типов:

| Тип | Что это | Пример |
|---|---|---|
| Count | количество | выполнено задач, прочитано страниц |
| Duration | время | время до начала работы, длина фокуса |
| Rate | доля | 8/10 правильных ответов |
| Score | субъективная оценка 1–5 | насколько легко было начать |
| Binary | да/нет | применял ли метод |
| Note | наблюдение | что мешало, что помогло |

Ровно одна метрика — главная (primary): она обязательна в каждом чек-ине и определяет вердикт. У главной метрики обязательно задаётся направление: «больше — лучше» или «меньше — лучше».

## Baseline

Baseline — твоё среднее значение до эксперимента: с ним Orbit сравнивает результаты и показывает «−33%» вместо голой цифры. Задаётся на конкретную метрику конкретной версии.

- нет — сравнивать не с чем, Orbit покажет только средние значения;
- вручную — вводишь своё среднее сам;
- из истории — среднее твоих чек-инов из прошлых завершённых версий этого же эксперимента (появляется со второй версии).

Baseline замораживается при старте версии и не меняется задним числом — иначе сравнение теряет смысл. Если понял, что ошибся, — новая версия с новым baseline.

## Чек-ин

Один чек-ин в день. Главная метрика обязательна, остальные — по желанию, заметка короткая. Пропущенный день — просто пустая точка в данных: забег не продлевается и не штрафуется. Регулярность видна как процент в результатах.

## Жизненный цикл версии

draft → running → ended → completed

Черновик можно редактировать. Запуск фиксирует метрики и baseline. Забег длится заданное число дней по календарю. После последнего дня версия ждёт итога: короткая обязательная рефлексия — сработало ли изменение. Рефлексия завершает версию и включает её в статистику семьи. Прерванная версия в статистику не входит.

## Результаты и вердикт

Для каждой метрики Orbit считает: среднее, минимум, максимум, изменение в % относительно baseline, динамику (вторая половина забега лучше первой?), регулярность.

Вердикт строится по главной метрике: улучшение / ухудшение / без изменений. Без baseline — «не с чем сравнивать»; без данных — «нет данных». Вердикт не решает за тебя — продолжать или нет, решаешь ты: рефлексия и есть твой вывод.

## Сравнение версий

Лучшая версия определяется среди завершённых с одинаковой главной метрикой (тип, единица, направление): побеждает максимальное улучшение относительно baseline. Разные метрики не сравниваются — так честно.
